# v1.0.0 — 首个公开版本

`douyin-live-alert`（抖抖先知）是一个无需登录抖音、无需 Chromium 的开播监控服务。它通过 Cloudflare Workers 定时查询主播状态，使用 D1 持久化状态与幂等事件，并通过飞书机器人私聊发送提醒。

## 主要能力

- 支持抖音主页链接和分享短链，按 `sec_uid` 统一去重。
- 使用 HTTP 接口轮询，不依赖浏览器、Cookie 或抖音账号。
- 只在 `offline -> live` 或直播间 ID 变化时提醒。
- 首次观测仅建立基线，不会在刚部署时误发通知。
- 使用 D1 唯一事件键与调度租约抵抗重复 Cron 和函数重试。
- 通知失败采用指数退避，最多重试五次。
- 针对 Cloudflare 免费额度限制了轮询和发信并发。
- 默认提供个人飞书扫码配置与机器人私聊通知。
- 附带企业微信群机器人、企业微信自建应用的接入文档。

## AI Native 部署

仓库提供 `AGENTS.md`、`config.schema.json` 和 `deploy.manifest.json`。能操作终端的 AI 可以遵循约束完成依赖安装、配置检查、D1 迁移、Worker 部署、健康检查和主播初始化，并且未经用户明确授权不得发送测试通知。

## 已知限制

- 抖音接口不是稳定的公开契约，平台变更可能导致解析失效。
- 免费 Serverless 受执行时间、子请求数和并发连接数限制。
- 当前完整实现以飞书通知为主；微信小程序版受订阅消息次数额度限制，未包含在本版本中。

## 安全说明

所有密钥均应通过环境变量或 Cloudflare Worker Secret 配置。不要提交真实订阅列表、应用凭证、用户标识或本地 D1 配置。

> 本项目是非官方工具，与抖音、飞书、Cloudflare 均无隶属或背书关系。使用者需自行遵守相关平台规则。
